# HopeCorePlayer

[English](./README.md)

Bağımlılıksız (hls.js hariç), TypeScript + Shadow DOM + Tailwind tabanlı, framework-agnostic bir `<hope-player>` custom element'i. Düz HTML, React, Vue, Next.js — hepsinde aynı şekilde çalışır.

Kurulum rehberi, canlı demolar ve tüm options/tema/plugin referansı: **[umutyaldiz.com/hopecoreplayer](https://umutyaldiz.com/hopecoreplayer)**

## Kurulum

```bash
npm install
npm run build:core   # @hopeplayer/core'u derler (dist/hope-player.js)
npm run dev          # apps/playground'u Vite dev server'da açar
```

## Yapı

```
packages/core     — <hope-player> custom element (sıfır çalışma zamanı bağımlılığı)
packages/react    — ince React wrapper
packages/vue      — ince Vue 3 wrapper (aynı mimari: mount sonrası dinamik import, prop/event köprüsü)
apps/playground   — düz HTML/TS dev ortamı
apps/demo-next    — Next.js demo
apps/demo-vue     — Vite + Vue 3 demo
apps/docs         — swiperjs.com tarzı kurulum + canlı demo sitesi (statik export; bu repoya/npm'e dahil DEĞİL — bkz. .gitignore, umutyaldiz.com'da ayrıca yayınlanıyor)
docs/             — mimari/plugin/tema dokümantasyonu
```

**Faz 0 — İskelet. ✅ Faz 1 — Çekirdek oynatma. ✅ Faz 2 — Reklam çekirdeği. ✅ Faz 3 — Prebid + Consent. ✅ Faz 4 — Etkileşim/layout. ✅ Faz 5 — İçerik-ops. ✅ Faz 6 — Canlı yayın. ✅ Faz 7 — Tema & dokümantasyon. ✅ Faz 8 — React wrapper + demo. ✅ Faz 8b — Vue 3 wrapper + demo. ✅**

- **`packages/vue`** (`HopePlayer` component, istek üzerine: "web-react gibi 2 tablı... belki next-vue gibi frameworkler için bile olabilir") — `packages/react` ile BİREBİR aynı mimari: `<script setup>` SFC, mount sonrası `onMounted` içinde dinamik `import('@hopeplayer/core')`, prop'lar `.options`'a tek seferde yazılıyor (`watch(() => JSON.stringify(props), ...)` — React'teki `useEffect([JSON.stringify(options)])` ile aynı desen), `hp:*` CustomEvent'leri Vue `emit`'lerine çevriliyor, `defineExpose({ play, pause, getElement })` ile imperatif erişim (`useTemplateRef<InstanceType<typeof HopePlayer>>`). **Gerçek bug (bulundu — "Maximum call stack size exceeded")**: `hope-player` tag'i `isCustomElement` AÇIKÇA Vite/`@vitejs/plugin-vue` yapılandırmasına verilmeden derlenirse, Vue'nun compiler'ı onu `resolveComponent()` ile bir component olarak çözmeye çalışıyor ve (bu paketin kendi SFC derleme bağlamında) sonsuz bir döngüye giriyordu — çözüm `packages/vue/vite.config.ts`'te `template.compilerOptions.isCustomElement: (tag) => tag === 'hope-player'`. **İkinci gerçek bug (bulundu — "@ready hiç ateşlenmiyor")**: olay dinleyicileri eskiden dinamik import'un `.then()`'i içindeydi, ama `hp:ready` `customElements.define()`'ın SENKRON upgrade'i sırasında (o da AYNI import tarafından tetikleniyor) zaten dispatch ediliyordu — dinleyiciler `.then()`'den ÖNCE, `onMounted` içinde senkron olarak eklenecek şekilde taşındı (`addEventListener`, `.options` setter'ının aksine upgrade'den önce de güvenle çağrılabilir). Her ikisi de `apps/demo-vue` + `vue-wrapper.e2e.mjs` ile gerçek bir tarayıcıda doğrulandı.

Performans: kurulumda hiçbir şey indirilmiyor (ilk seek bar hover'ı / `play`), yalnızca imlecin altındaki sheet + `preloadSheets` (vars. 1) komşu yükleniyor, `decode()` bitmeden gösterilmiyor, LRU cache en fazla 8 sheet, çizim rAF ile sınırlı; zaman eşlemesi `SeekBar.ratioAtClientX` (chapter boşlukları dahil); önizleme kenarlarda taşmıyor ve altında zaman yazıyor (segments popup'ı bu durumda zamanı tekrar yazmıyor). **Eski halinde bulunan gerçek bug'lar:** (1) şablonsuz tek sprite'ta varsayılan `sheetDuration: 300` yüzünden 5. dakikadan sonra zaman başa sarıyor, yanlış kare gösteriliyordu; (2) sheet sınırında `ceil` yüzünden önceki sheet'in olmayan karesi isteniyordu; (3) tüm sheet'lerin boyutu 1. sheet'ten alınıyordu (kısa son sheet gerilirdi). Demo/test görselleri ffmpeg ile `sample.mp4`'ten üretildi (`sprite.jpg` 4×4 tek sheet, `sprite-1..4.jpg` 2×2 çok parçalı, `thumbs.vtt`). Regresyon: `content-ops.e2e.mjs` senaryo 3b (lazy yükleme, doğru kare/zaman, kenarda taşmama, son kare, otomatik `sheetDuration`, komşu ön yükleme + uzak sheet'in indirilmemesi, sheet sınırı, VTT `#xywh`, 3 saatlik video simülasyonunda yalnızca 3 sheet isteği).

- **Seek bar'da varsayılan hover zamanı** (istek üzerine: "seekbar'da mouse'la gezinirken zaman gösteriliyor ya, o default'ta da olsun") — `SeekBar` artık plugin olmadan imlecin üstünde zamanı gösteriyor (`part="seek-time"`, tooltip token'ları, kenarlarda taşmıyor, chapter boşluklarını hesaba katan `ratioAtClientX`). Kendi zamanını gösteren plugin'ler (sprite önizlemesi, segments popup'ı) `seekBar.suppressHoverTime(key, true)` ile gizliyor (keyed set — `blockChrome` gibi); canlı yayında (`duration === Infinity`) gösterilmiyor. Regresyon: `theme.e2e.mjs` 1b + `content-ops.e2e.mjs` (segments/sprite açıkken iki kez yazılmaması).
- **Örnek video altyazıları videoyu anlatıyor** — eski "Faz 1 test altyazısı" metinleri yerine dağlar, bulutlar, kar şeritli yamaçlar ve krater gölünü anlatan 5 cue (TR `sample.vtt` + yeni EN `sample.en.vtt`; docs + playground + demo-next + demo-vue). Docs'ta ana sayfa/temel oynatma/ayarlar demolarında iki iz birden, varsayılan sayfanın dili (`lib/sampleSubtitles.ts`); altyazı sayfasındaki düzenleyici aynı anlatımla dolu ve açılışta otomatik uygulanıyor.

- **Mobil / küçük player düzeni** (istek üzerine: "mobilde sağ toolbar grubunu sağ üste koyalım, sıkışık olmasın"). **Gerçek bir bug bulundu:** 360px'lik bir telefonda dokunmatik için 40px'e büyüyen butonlarla iki grup tek satıra sığmıyor, **tam ekran butonu player'ın dışına taşıp görünmüyordu**. Artık `ControlBar` player'ın KENDİ genişliğini (ekranı değil — küçük bir masaüstü player'ı ya da sticky dock da aynı düzeni alıyor) ResizeObserver ile izliyor; 480px altında kompakt düzen: sağ grup (ayarlar + plugin butonları + PIP) üst sağdaki `part="top-bar"`a taşınıyor (chrome'la birlikte otomatik gizlenir), tam ekran altta sağda kalıyor (YouTube mobil düzeni). Dokunmatikte (`(hover: none) and (pointer: coarse)`) ses butonu gizli — ses donanım tuşlarıyla; ama sessiz başlayan videolarda sesi açmanın yolu kalsın diye video sessiz OYNARKEN sol üstte **"Sesi aç" rozeti** (`part="unmute-badge"`) çıkıyor: chrome katmanının dışında (kontroller gizlense de görünür), tek dokunuşla sesi açıyor (toggle değil; reklam sırasında reklamın sesini), videoya dokunma (oynat/duraklat) olarak sayılmıyor.
- **Altyazı mobilde en alta inebiliyor** (istek üzerine: "mobilde altyazı en alta kadar gelebilmeli, tam ortada kalıyor"). Kök sebep: altyazının en alt konumu HER ZAMAN seek bar'ın üstü olarak hesaplanıyordu — kontroller gizliyken bile; mobilde kontrol çubuğu yüksek olduğundan altyazı küçük player'ın ortasında kalıyordu. Chrome görünürlüğü artık tek bir `setChromeOpacity()`'den geçiyor ve `CaptionRenderer.setChromeVisible()`'a bildiriliyor: kontroller görünürken seek bar'ın üstünde, gizlenince yumuşak geçişle en altta (video yüksekliğinin %4'ü, en az 10px) — kullanıcının sürükleyip seçtiği satır korunuyor. Kompakt düzende altyazı 13px (dokunmatik 19px küçük player'da iki satıra taşıp üst barla/merkez butonla çakışıyordu) ve seek bar üstü boşluk 6px. Regresyon: yeni `mobile.e2e.mjs` (`npm run test:mobile`, gerçek dokunmatik emülasyonu: kompakt düzen + taşmama, ses butonu gizli, "Sesi aç" rozeti görünür/otomatik gizlenmez/dokununca ses açılır ve oynatma durmaz, masaüstünde rozet yok, canlı yeniden boyutlandırma, altyazının kontroller gizlenince 98px → 10px inmesi).

- **Dokunmatikte buton tooltip'leri kapalı** (istek üzerine: "mobilde buton tooltiplerini gizle, boşuna çıkmasınlar") — butona dokunmak hem `mouseover` hem `focusin` tetiklediği için tooltip boşuna açılıyordu; `Tooltip.show()` artık yalnızca `(hover: hover)` cihazlarda gösteriyor. Seek bar'da parmakla sürüklerken zaman/önizlemeler (işe yaradıkları için) duruyor. Regresyon: `mobile.e2e.mjs` senaryo 1 (ayarlar butonuna gerçek dokunuş → tooltip yok).

- **Docs sitesi: site içi arama** (istek üzerine, tailwindcss.com'daki gibi) — `⌘K` (Mac) / `Ctrl+K`, ya da `/`; header'da "Ara…" butonu (kısayol etiketi işletim sistemine göre). Tüm sayfaları VE her sayfadaki parametreleri arar (ör. `holdRate`, `retry.maxAttemptsPerTag`); Türkçe karakter duyarsız ("sayim" → "Geri Sayım"), çok kelimeli (AND), başlık eşleşmeleri öne çıkar, eşleşen kısım vurgulanır, ↑↓/↵/esc ile klavyeyle kullanılır. Parametre sonucu doğrudan o sayfadaki tablo satırına gidip satırı vurgular — hedef URL hash'inde (`/plugins/ima#opt-retry-maxattemptspertag`), bu yüzden bu linkler paylaşılabilir. Dizin build zamanında sunucuda üretiliyor (`lib/searchIndex.ts`), tarayıcıya tüm içerik değil küçük bir dizin gidiyor. Pencere `<body>`'ye portal ile render ediliyor (sticky nav'ın stacking context'inde kalınca sayfadaki player'ın katmanları üstüne çıkıyordu). Header responsive: 520px altında "Kurulum/Özellikler" metin linkleri gizli (sidebar "Sayfalar" menüsü, anasayfa butonları ve arama üzerinden erişiliyor), arama yalnızca ikon — 320–1440px'te taşma yok.

- **`miniProgress` seçeneği** (istek üzerine: "player'dan çıktıktan sonra seekbar 1px yükseklikle sağa sola dayanmış şekilde en altta görünsün, bir ayara bağla") — `options.miniProgress: true` (varsayılan `false`) iken kontroller gizlenince video alanının en altında kenardan kenara 1px ilerleme çizgisi (`part="mini-progress"`, played = accent, buffered = soluk) görünüyor; kontroller gelince kayboluyor. Görünürlük `setChromeOpacity()` + chrome bloklayıcılarından (reklam/giriş ekranları sırasında gizli), canlı yayında (`duration === Infinity`) gösterilmiyor; çizim yalnızca görünürken ve oynarken rAF ile. Docs'ta yalnızca anasayfa player'ında açık; "Zaman Çubuğu" sayfasına parametre + `::part(mini-progress)` eklendi. Yan düzeltme: `autoHideDelayMs` JSDoc'u "Varsayılan 2500" diyordu, gerçek değer 1200. Regresyon: `theme.e2e.mjs` 1c.

- **Kalan süre gösterimi / toggle** (istek üzerine: "0:05 / 0:15 gösteriminin üstüne basınca toggle şekilde çalışsın, -0:10 / 0:15 şeklinde gösterebilsin") — kontrol çubuğundaki süre göstergesi artık tıklanabilir bir buton (`part="time-display"`, `cursor: pointer`). Tıklandığında geçen süre (`0:05 / 0:15`) ile kalan süre (`-0:10 / 0:15`) arasında toggle yapar. Ayrıca `options.showRemainingTime: true` ile başlangıçta kalan süre modu seçilebilir, `player.showRemainingTime` getter/setter'ı ve `player.toggleTimeDisplay()` API metodu ile programatik olarak yönetilebilir. Canlı yayında (`duration === Infinity`) ve reklam modunda gizli kalmaya devam eder. Tooltip'in süreyi kapatmaması için `Tooltip` hariç tutma listesine eklendi. Regresyon: `interaction.e2e.mjs` senaryo 12.

## Yayınlama (release)

`packages/core`/`react`/`vue`, GitHub'da bir **release** (`v1.0.0` gibi bir tag) oluşturulunca `.github/workflows/publish.yml` tarafından otomatik olarak npm'e yayınlanır — npm'in **OIDC Trusted Publishing**'i kullanılıyor, yani depoda `NPM_TOKEN`/`NODE_AUTH_TOKEN` secret'ı YOK; npmjs.com'da üç paket için de bu repo + `publish.yml` workflow'u "Trusted Publisher" olarak tanımlanmış olmalı (npmjs.com → paket → Settings → Trusted Publishers). Yeni bir sürüm çıkarmak için: üç paketin `package.json`'larındaki `version`'ı güncelleyip commit'le, sonra GitHub'da o sürümle eşleşen bir tag'li release oluştur — workflow core → react → vue sırasıyla build edip yayınlar.

`.github/workflows/ci.yml` her push/PR'da `typecheck` + üç paketin build'ini çalıştırır (ayrı bir onay/secret gerektirmez).
